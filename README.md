ChemTox Profiler (Windows Desktop App)
ChemTox Profiler — это инструмент для быстрой оценки безопасности и биологической активности химических соединений. Приложение работает локально на Windows, не требует настройки окружения и использует современные ML-модели для прогноза.
 Основные возможности
Ввод структуры: Поддержка SMILES и InChI.

ADMET-AI (Токсичность): Прогноз блокировки калиевых каналов (hERG), повреждения печени (DILI), мутагенности (Ames) и острой токсичности (LD50). Результаты LD50 автоматически конвертируются в мг/кг с указанием класса опасности по GHS.

ESKAPE (Антибактериальная активность): Оценка вероятности активности против шести ключевых патогенов (Enterococcus faecium, Staphylococcus aureus, Klebsiella pneumoniae, Acinetobacter baumannii, Pseudomonas aeruginosa, Escherichia coli).

Antifungal (Противогрибковая активность): Эвристический поиск типичных противогрибковых структурных блоков.

Справочные данные: Возможность вручную ввести литературные значения LD50 (включая внутрибрюшинное введение) для сравнения с прогнозом.

Скачать и установить
Готовый установщик (.exe) доступен в разделе Releases.

Скачайте ChemTox_Setup.exe.

Запустите и следуйте инструкциям (ярлык появится на рабочем столе).
