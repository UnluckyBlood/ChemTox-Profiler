# ChemTox Profiler v1.1.0

Десктопное приложение для прогнозирования токсичности (ADMET-AI), антибактериальной активности (ESKAPE, Random Forest) и профиля биоактивности (ChEMBL Multitask) по SMILES-строке.

## Запуск на Windows

В проекте используется изолированный портативный Python. Вам не нужно устанавливать зависимости в систему.

### Способ 1: Через скрипт-обертку (рекомендуется)
1. Откройте командную строку (cmd) или PowerShell в папке проекта.
2. Выполните: `python start.py`
Скрипт найдет портативный Python и запустит программу в отдельном нативном окне.

### Способ 2: Прямой запуск
Если вы хотите запустить приложение напрямую, используйте только портативный Python из папки проекта:
`python\pythonw.exe launcher.py`

## Запуск на Linux (Debian/Ubuntu)

Для работы на Linux требуются системные библиотеки для графического интерфейса и сборки пакетов.

### Подготовка системы
Откройте терминал и установите зависимости:
`sudo apt update`
`sudo apt install python3 python3-venv python3-pip build-essential libgirepository1.0-dev gobject-introspection libcairo2-dev pkg-config libgl1`

### Запуск
1. Перейдите в папку с проектом.
2. Выполните: `python3 start.py`
Скрипт создаст виртуальное окружение `venv`, установит все библиотеки из `requirements.txt` и запустит приложение. При последующих запусках установка выполняться не будет.

## Установка и проверка (Windows)
Запустите `install.bat`: он выполняет основную установку (`setup.ps1`), затем `check_install.py` проверяет Python, библиотеки, 7 RF-моделей ESKAPE (и LFS-заглушки), модель биоактивности ChEMBL, докачивает недостающее, делает самотест расчёта и сразу запускает приложение. `launch.bat` при проблемах сам вызывает `install.bat`.

Проверку можно запускать отдельно: `python\python.exe check_install.py` (`--check-only` — ничего не скачивать, `--launch` — запустить после проверки). На Linux: `./venv/bin/python check_install.py`.

## Структура проекта
- `start.py` - Универсальный скрипт запуска
- `launcher.py` - Точка входа для Windows (pywebview окно)
- `streamlit_app.py` - Графический интерфейс и логика расчетов
- `check_install.py` - Проверка установки, докачка моделей, самотест и запуск
- `install.bat` / `launch.bat` - Установка с проверкой и запуск (Windows)
- `activity_profiler.py` - Профиль биоактивности (модель ChEMBL Multitask, ONNX); также работает как консольная утилита
- `python/` - Портативный Python 3.10 (только для Windows)
- `db/` - Веса моделей Random Forest и канонические данные
- `requirements.txt` - Зависимости для Linux

## Функционал
- Прогноз токсичности (ADMET-AI): hERG, DILI, Ames, LD50 (мг/кг и GHS).
- Прогноз антибактериальной активности (ESKAPE): 7 приоритетных патогенов.
- Поиск противогрибковых SMARTS-паттернов.
- Расчет физико-химических дескрипторов (MW, LogP, TPSA).
- Профиль биоактивности по 11 классам (противовоспалительная, противоопухолевая, анальгетическая и др.) на основе вероятностей связывания с ~800 белковыми мишенями ChEMBL.

## Профиль биоактивности
Модель (~10 МБ: `chembl_37_multitask.onnx` и `targets_37_all.json`) скачивается с GitHub (chembl/chembl_multitask_model) при первом расчёте в `db/models/chembl/`, дальше работает офлайн. Для полностью автономной сборки положите эти два файла в `db/models/chembl/` заранее.

На Windows в портативный Python нужно один раз доустановить пакет: `python\python.exe -m pip install onnxruntime`.

Результат — механистическая гипотеза для приоритизации (вероятность сильного связывания с мишенями класса), а не доказательство клинической активности и не значение Pa из PASS. Консольный режим: `python activity_profiler.py -i molecules.csv -o result.csv`.
