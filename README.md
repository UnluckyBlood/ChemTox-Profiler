# ChemTox Profiler - Windows Build & Installer

Этот репозиторий содержит скрипты для сборки десктопной версии ChemTox Profiler (без браузера) и создания установщика setup.exe.

## Инструкция по сборке:
1. Скопируйте в эту папку окружение python и папку db (модели) из основного проекта.
2. Запустите uild.bat двойным кликом.
3. Готовый ChemTox_Setup.exe появится в папке Output.
