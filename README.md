
***

ChemTox Profiler - это десктопное приложение для Windows, предназначенное для быстрого прогноза токсичности и биологической активности химических соединений. Программа работает локально, не требует установки Python, настройки окружения или доступа к интернету. Ввод структуры осуществляется через SMILES или InChI.

Основные возможности программы:
- Прогноз острой токсичности (LD50) с автоматическим переводом в мг/кг и определением класса опасности по системе GHS.
- Оценка токсикологического профиля: кардиотоксичность (hERG), гепатотоксичность (DILI), мутагенность (Ames).
- Прогноз антибактериальной активности (ESKAPE) против шести клинически значимых патогенов.
- Поиск типичных противогрибковых фармакофоров (азолы, полиены, галоген-ароматика).
- Возможность вручную ввести справочные значения LD50 (включая внутрибрюшинное введение) для сравнения с прогнозом модели.
- Интерактивные графики и цветовая индикация рисков (светофор).

Установка:
1. Скачайте установщик ChemTox_Setup.exe по ссылке.
2. Запустите его и дождитесь окончания установки.
3. На рабочем столе появится ярлык ChemTox Profiler. При запуске программа откроется в отдельном окне (без интерфейса браузера).
